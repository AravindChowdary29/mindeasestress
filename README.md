MindEase is a simple stress self check website that I built to help people take a moment to reflect on how they have been feeling lately.

The website asks a few questions related to stress and everyday experiences, then provides general feedback and some practical suggestions based on the responses.

MindEase is meant to be a tool for self-reflection. It is not a medical or mental health diagnostic tool.
